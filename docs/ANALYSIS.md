## 六、方法与边界

- 日条解析：行首日期标记（干支纪年/闰月/晦朔/廿X日）+ 句末标点后日号分段 → 506 日条
- 锚点：篇内 scope 消歧地名表逐日首现（避开前一锚同名），坐标今地近似（确 ±3km 级 / 推 ±10–25km 级）
- 已知误锚风险：文本提及而未亲历之地（如楚游述及安福）会占锚——scope 表已消歧 47 组同名，
  存疑处以 conf=推 与 ⚠跳段 双重标示
